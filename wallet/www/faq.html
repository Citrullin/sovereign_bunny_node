Sovereign Wallet FAQ

Local-First Architecture, Browser Limits, and Post-Quantum Security Reference

1. Browser Compatibility & Workarounds

⚠️ WARNING: Only Chromium-based browsers (Chrome, Brave, Edge, Opera) support full native Filesystem APIs. You will experience inconveniences in other browsers.

Why does the app warn me about my browser?

This app uses the W3C File System Access API to store your DID document, private keys, intent escrows, and NFT assets directly in a local directory on your disk (e.g. data/[DID]/). Only Chromium-based browsers support opening and editing local folders natively.

Firefox & Safari Workaround Guide

If you use Firefox or Safari, you cannot select a persistent directory. Instead, follow these steps:

  1. When prompted, use the Export Backup (.zip) button to download your wallet files.
  2. Every time you open the app, upload your latest backup zip file using the file selector.
  3. We highly recommend switching to a Chromium-based browser to experience seamless local-first auto-saves.

2. Post-Quantum Security & Keys

What keys does this wallet generate?

When initialized, the wallet uses WebAssembly to derive six cryptographic keys from your master seed:

  • secp256k1: Classical EVM signing key (compatible with Rabby/MetaMask).
  • Ed25519: Classical EdDSA key used for peer-to-peer messaging and W3C Verifiable Credentials.
  • BLS12-381: Sync committee signature aggregation key.
  • ML-DSA-87: CRYSTALS-Dilithium5 post-quantum signing key.
  • SLH-DSA: SPHINCS+ post-quantum signing key.
  • Falcon-512: Post-quantum signing key.

How do I back up my keys?

Since this is a local-first wallet, we never run server-side backups. Go to Settings -> Export Key Backup and download the encrypted ZIP. The backup is encrypted using Argon2id and AES-256-GCM derived from your password.

3. Cross-Chain NFT Sales & Intent Resolver

How does the NFT sale work without bridges?

Instead of a custodial bridge, we use a Saga Intent Resolver model:

  1. You sign a purchase intent stating you will pay a fixed amount of EURe (regulated stablecoin) on Gnosis Chain.
  2. The Snowman consensus sub-committee monitors Gnosis Chain for your payment receipt.
  3. Once payment is confirmed, the sub-committee updates the Verkle state tree on the stateless chain to assign the NFT to your address.
  4. Your wallet fetches the updated Verkle witness proof, and the NFT is fully yours.

4. NFC e-Paper Displays

How do I write my NFT to the NFC e-Paper?

The app supports flashing your NFT image directly to a 1.54" NFC-Powered e-Paper display:

  1. Open this dApp in Chrome on Android (which supports Web NFC).
  2. Click Flash to e-Paper on your NFT card.
  3. Hold your epaper display against the NFC antenna of your phone.

If you are on desktop or a non-compatible device, click Download Bin to save the dithered image data, and use the epaper Android App to flash it.

5. Auditability

How do I verify this app is safe?

This app is packaged as a single HTML file with zero remote fetches (no CDN, no external scripts). You can audit it easily:

  1. Open this HTML file in any plain text editor.
  2. Paste the code into an LLM or run static analysis.
  3. Verify there are no remote API keys, tracking, or network calls other than your local node RPC.
